# 光伏收益分析系统 — 使用说明

---

## 一、安装与启动

### 1.1 运行前提

- **操作系统**：Windows 10（较新版本）或 Windows 11
- **WebView2 Runtime**：程序依赖系统 WebView2 内核。Windows 10（较新版本）和 Windows 11 通常已自带，如果启动后窗口空白或无法显示内容，请安装 [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section)，选择「Evergreen Standalone Installer」下载安装即可。

### 1.2 启动方式

双击 **`光伏收益分析系统.exe`** 即可运行。程序会自动打开一个独立窗口，无需安装 Python 或其他依赖。

> 注意：程序是单文件 EXE，建议放在固定目录（如桌面或专用文件夹），不要放在临时位置以免误删。

### 1.3 数据存储位置

所有项目数据通过 localStorage 持久化存储，存储目录为：
```
%LOCALAPPDATA%\光伏收益分析系统\
```
即 `C:\Users\你的用户名\AppData\Local\光伏收益分析系统\`

> ⚠️ 不要手动删除此目录，否则所有项目数据将丢失。

## 二、首次使用 — 系统设置

### 2.1 设置公司信息

首次启动后，页头会显示"请在系统设置中填写公司信息"。请先完成基础设置：

1. 点击页头右侧 **⚙️ 设置** 按钮
2. 在弹窗中填写：
   - **公司名称**（必填）：例如"某某新能源科技有限公司"
   - **公司地址**（可选）：例如"某某省某某市某某路某某号"
   - **联系电话**（可选）：例如"0318-2116018"
3. 点击 **💾 保存设置**

设置保存后：
- 页头会自动显示"某某新能源科技有限公司 · 某某路某某号 · 0318-2116018"
- 所有已存在的项目的公司信息会同步更新
- 导出报告的页眉会自动显示您设置的公司信息

## 三、项目管理

### 3.1 新建项目

1. 在页头下方项目栏点击 **➕ 新建项目** 按钮
2. 在弹窗中填写：
   - **项目名称**：例如"胜利路屋顶电站"
   - **总投资金额**（元）：电站的总投入成本，例如"800000"
   - **装机容量**（kW）：电站的装机功率，例如"100"
   - **起始月份**：电站开始运行的月份，例如"2024-01"
3. 点击确认，项目创建完成

> 💡 项目名称、总投资、装机容量、起始月份在创建后**不可修改**，请确认无误后再创建。

### 3.2 切换项目

在项目栏的 **📂 项目切换** 下拉框中选择不同项目，所有数据和图表会自动刷新为该项目的数据。

### 3.3 删除项目

点击 **🗑️ 删除项目** 按钮，系统会弹出确认提示，确认后删除当前项目及其所有数据。

> ⚠️ 删除操作不可恢复，请确保已备份重要数据。

### 3.4 批量操作

点击 **📦 批量操作** 按钮，可对多个项目进行批量数据操作（如批量导出、批量设置等）。

## 四、仪表盘（首页）

仪表盘是系统的核心页面，启动后默认显示当前项目的总览信息。

### 4.1 KPI 指标区

页面顶部展示五大关键指标：

| 指标 | 说明 |
|------|------|
| 系统总投资 | 项目创建时设定的投入金额 |
| 累计电费收益 | 直接收益 + 间接收益的总和 |
| 回本进度 | 累计电费收益 ÷ 总投资 × 100% |
| 累计减排 | 根据发电量计算的 CO₂ 减排量 |
| 装机容量 | 项目创建时设定的装机功率 |

### 4.2 项目信息与参数设置

- **项目信息卡**：显示项目名称、总投资、装机容量、起始月份（不可修改）
- **参数设置卡**：购电均价可修改（影响间接收益计算），装机容量显示（不可修改）
- **分段电价卡**：可设置两段不同月份的上网电价，系统根据当前月份自动匹配适用电价

### 4.3 收益构成区

展示收益的三大来源：
- **直接收益**：上网电量 × 上网电价（卖给电网的钱）
- **间接收益**：自用电量 × 购电均价（省下的电费）
- **绿证收益**：绿证出售记录汇总

### 4.4 回本进度条

- 实时显示回本百分比，带里程碑标记（25%/50%/75%/100%）
- 显示已回本金额、待回本金额、预计回本天数
- 回本后自动切换为"盈利里程碑"模式，每净赚 1 万元触发一次标记

### 4.5 投资与收益明细

展示更详细的财务指标：
- 已回本金、待回本金、累计盈利
- 年均/月均/日均电费收益
- 累计减排（折算植树棵数）
- 平均自用率、累计节省用电、累计节省电费
- 绿证相关指标（可交易/不可交易绿证数量、绿证总收益）

### 4.6 财务分析区

专业财务评估指标：

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| IRR（内部收益率） | 项目真实收益率 | 使 NPV = 0 的折现率（迭代求解） |
| NPV（净现值） | 25年折现收益 | Σ(年收益/(1+折现率)^年) - 总投资 |
| 动态投资回收期 | 考虑折现的回收年限 | 累计折现收益首次≥投资的年份 |
| 静态投资回收期 | 不考虑折现的回收年限 | 累计收益首次≥投资的年份 |
| ROI（投资回报率） | 总收益与投资之比 | 累计收益 ÷ 总投资 × 100% |

IRR 评级徽章参考标准：
- 🏆 优秀：IRR ≥ 15%
- ✅ 良好：IRR ≥ 10%
- ⚠️ 一般：IRR ≥ 5%
- ❌ 偏低：IRR < 5%

> 💡 财务分析区可点击"收起/展开"按钮切换显示状态。

## 五、月度账单录入

### 5.1 录入月度数据

1. 点击「月度账单」标签页
2. 点击 **➕ 新增** 按钮，添加一行新的月度记录
3. 填写以下字段：
   - **月份**：选择对应月份（如 2024-01）
   - **总发电（度）**：逆变器显示的总发电量
   - **上网（度）**：卖给电网的电量
   - **自用（度）**：自己使用的电量
   - **电网账单收益（元）**：电力局实际结算金额（可选，如填写则以此为准）

4. 系统自动计算：
   - 直接收益 = 上网电量 × 对应上网电价
   - 间接收益 = 自用电量 × 购电均价
   - 最终收益 = 电网账单收益（如果填写），否则 = 直接收益
   - 总收益 = 最终收益 + 间接收益

### 5.2 分段电价说明

如果不同时期上网电价不同（如政策调整），可在仪表盘的"分段电价"区域设置：
- 第一段：起始月份 + 对应电价
- 第二段：起始月份 + 对应电价
- 系统根据每条月度记录的月份自动匹配适用电价

### 5.3 月度数据导入导出

- **导出**：点击 **📤 导出** 按钮，将月度数据导出为 CSV 文件
- **导入**：点击 **📥 导入** 按钮，从 CSV 文件导入月度数据
- **清空**：点击 **🗑️ 清空** 按钮，清空所有月度数据（需确认）

## 六、逐日发电追踪

### 6.1 录入每日数据

1. 点击「逐日追踪」标签页
2. 先点击 **📅 新增月度**，选择要录入的月份
3. 在矩阵表格中，横排为1-31日，竖排为月份
4. 在对应单元格输入当日逆变器显示的发电量（度）
5. 输入后自动跳转到下一个日期单元格

### 6.2 数据说明

- 逐日数据来源于**逆变器**，仅用于查看日度发电趋势
- **收益计算以「月度账单」中录入的电力局结算数据为准**
- 顶部浮动统计栏显示：累计天数、总发电量、日均发电、月均发电、覆盖月数

### 6.3 逐日数据导入导出

- **导出**：导出为 CSV 文件
- **导入**：从 CSV 文件导入逐日数据
- **清空**：清空所有逐日数据（需确认）

## 七、安装前后对比分析

### 7.1 录入安装前数据

1. 点击「对比分析」标签页（安装前后市电购入对比）
2. 录入光伏安装前各月的市电购入量（度）
3. 黄色标记的行是安装后的月份

> 💡 输入数值后按 Enter 键自动跳转到下一个单元格。双击单元格可直接修改。

### 7.2 安装效果对比

切换到「效果对比」标签页，系统自动计算以下指标：

- **累计节省市电**：安装后 vs 安装前同期的市电减少量
- **累计节省率**：安装后市电下降比例
- **累计电费收益**：直接收益 + 间接收益
- **平均自用率**：安装后平均自用比例
- **累计发电量**：自安装以来总发电量
- **安装后用电变化**：总体用电上浮或下降比例

## 八、绿色证书管理

### 8.1 录入绿证出售记录

1. 点击「绿色证书」标签页
2. 点击 **➕ 新增出售记录** 按钮
3. 填写：
   - **出售日期**：绿证出售的日期
   - **出售张数**：本次出售的绿证数量（1张 = 1000度）
   - **出售单价（元）**：每张绿证的出售价格
   - **备注**：可选备注信息

系统自动计算：
- 本次金额 = 出售张数 × 出售单价
- 总出售张数、总收益、加权均价

### 8.2 绿证数量说明

- **可交易绿证**：上网电量 ÷ 1000 度/张
- **不可交易绿证**：自用电量 ÷ 1000 度/张

### 8.3 绿证数据图表

- 绿证出售趋势图：按时间展示出售数量和金额
- 绿证收益月度分布图：按月份展示收益分布

## 九、综合报表导出

### 9.1 生成报告

在项目栏点击相应按钮，系统一键生成独立 HTML 报告文件。报告包含：

1. **项目基本信息**：名称、投资、装机容量、起始月份
2. **KPI 指卡**：回本进度、ROI、累计收益等
3. **月度数据明细表**：所有月度发电与收益数据
4. **安装前后对比**：节省效果分析

6. **绿证数据**：出售记录汇总

### 9.2 报告特点

- 报告为独立 HTML 文件，可在任何浏览器中直接打开查看
- 包含 Chart.js 图表（柱状图、折线图、饼图等）
- 页眉自动显示您设置的公司名称、地址、电话
- 页脚标注"光伏收益分析系统 v11.0"和生成日期

## 十、数据管理

### 10.1 备份与恢复

- **💾 备份数据**：在项目栏点击备份按钮，将当前项目数据保存为 JSON 文件
- **📂 恢复数据**：选择之前备份的 JSON 文件，恢复项目数据

### 10.2 全局数据导出 / 导入

页头右侧的 **📤 导出** 和 **📥 导入** 按钮用于全局数据迁移：

- **导出**：将所有项目数据（所有 pv_ 开头的 localStorage 数据）导出为一个 JSON 文件
- **导入**：从 JSON 文件恢复数据到当前系统

#### 从浏览器版迁移数据到 EXE 版

1. 在浏览器中打开原来的 HTML 版本
2. 点击 **📤 导出** 按钮，下载 JSON 文件
3. 打开 EXE 版本
4. 点击 **📥 导入** 按钮，选择刚才下载的 JSON 文件
5. 系统自动识别格式（新版/旧版），确认覆盖数量后完成导入

> 💡 系统自动兼容旧版「全项目备份」格式，无需手动转换。

### 10.3 导出 CSV

点击 **📥 导出CSV** 按钮，可将月度数据、逐日数据、绿证数据导出为 CSV 格式，方便在 Excel 中进一步处理。

### 10.4 清空数据

点击 **🗑️ 清空数据** 按钮，清空当前项目的所有月度和逐日数据（需二次确认）。

> ⚠️ 清空操作不可恢复，请先备份再操作。

## 十二、常见问题

### Q1：启动后窗口空白

请确认已安装 WebView2 Runtime。Windows 11 和较新的 Windows 10 通常已自带。如未安装，访问 https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section 下载「Evergreen Standalone Installer」安装。

### Q2：数据丢失了

数据存储在 `%LOCALAPPDATA%\光伏收益分析系统\` 目录中。如果误删此目录，数据将丢失。建议定期使用「备份数据」功能导出 JSON 备份文件。

### Q3：EXE 版和浏览器版的数据会混淆吗

不会。EXE 版使用 WebView2 独立的 localStorage 存储空间，与浏览器完全隔离。两者互不影响，可以同时使用。

### Q4：如何从浏览器版迁移数据

参见第 10.2 节「从浏览器版迁移数据到 EXE 版」。使用页头的导出/导入按钮即可完成。

### Q5：导入旧版备份文件提示格式不对

系统已支持自动识别旧版「全项目备份」格式。如果仍然提示格式错误，请确认文件确实是本系统导出的数据文件，而非其他程序的文件。

### Q6：IRR 显示为 NaN 或负数

IRR 计算需要至少两年以上的月度收益数据，且累计收益需为正值。如果数据不足或收益为负，IRR 可能无法正常计算。

### Q7：分段电价如何设置

在仪表盘的"分段电价"区域设置两段电价及起始月份。系统会根据每条月度记录的月份自动匹配对应的电价。例如：
- 第一段：2024-01 起，电价 0.3932 元/度
- 第二段：2025-07 起，电价 0.3844 元/度

### Q8：项目名称/投资/装机容量能修改吗

这三个参数在项目创建时设定，创建后不可修改。如需修改，请删除旧项目并重新创建。
