# 光伏收益分析系统 — 软件介绍

## 一、软件概述

**光伏收益分析系统** 是一款专为分布式光伏电站投资方和运维方设计的桌面端收益管理工具。系统以项目为单位，完整追踪光伏电站从安装到运行全生命周期的电费收入、运维成本、投资回收和盈利状况，帮助用户清晰掌握每一座光伏电站的真实经济效益。

本系统基于 WebView2 内核封装为独立 EXE 程序，无需安装 Python 或浏览器，双击即可运行。所有数据通过本地持久化存储，不依赖任何云服务，确保数据安全与隐私。

---

## 二、核心功能

### 2.1 多项目管理

- 支持**创建多个独立项目**，每个项目拥有独立的装机容量、总投资、起始月份等参数
- 一键切换项目，所有数据与图表自动刷新
- 支持项目删除、批量操作、数据备份与恢复

### 2.2 仪表盘总览

- **五大 KPI 指标**：系统总投资、累计电费收益、回本进度、累计减排、装机容量
- **回本进度可视化**：实时进度条 + 里程碑标记 + 预计回本天数
- **盈利里程碑**：回本后每净赚 1 万元触发庆祝，激励持续关注收益
- **收益构成分解**：直接收益（上网售电）、间接收益（自用省电费）、绿证收益

### 2.3 月度账单录入

- 按电网结算账单逐月录入发电数据：总发电量、上网电量、自用电量
- 自动计算直接收益、间接收益、最终收益和总收益
- 支持电网账单收益直接录入，以实际结算为准
- **分段电价**：支持按月份设置不同上网电价，自动匹配当前适用电价
- 数据支持 CSV 导入导出

### 2.4 逐日发电追踪

- 按日录入逆变器发电数据，追踪每日发电趋势
- 横排日期、竖排月份的矩阵式录入，输入后自动跳转下一个单元格
- 显示累计天数、总发电量、日均发电、月均发电等统计指标
- 仅用于查看趋势，收益计算以月度账单数据为准

### 2.5 安装前后对比分析

- 录入光伏安装前各月市电购入量，系统自动计算安装后的节省效果
- **六大对比指标**：累计节省市电、节省率、电费收益、平均自用率、累计发电量、用电变化
- 四组对比图表：节省分析、效益占比、收益趋势、发电去向
- 月度对比明细表，逐月展示节省明细

### 2.6 绿色证书管理

- 录入绿证出售记录：出售日期、张数、单价、备注
- 自动汇总总出售张数、总收益、加权均价
- 绿证出售趋势图 + 收益月度分布图
- 支持绿证数据的导入导出

### 2.7 财务分析引擎

- **内部收益率（IRR）**：迭代计算使 NPV = 0 的折现率，反映项目真实收益率
- **净现值（NPV）**：25 年生命周期折现收益，折现率可自定义（默认 8%）
- **动态投资回收期**：考虑折现因素的投资回收年限
- **静态投资回收期**：不考虑折现的简单回收年限
- **投资回报率（ROI）**：总收益 / 总投资 × 100%
- IRR 评级徽章：优秀 / 良好 / 一般 / 偏低，直观判断项目质量

### 2.8 全项目汇总看板

- 所有项目核心数据一览：项目总数、总投资合计、总收益合计、总减排、平均回本进度
- **项目对比雷达图**：五维度（收益率、回本速度、自用率、发电稳定性、单位投资收益）直观对比
- 各项目投资回报排行 + 回本进度排行

### 2.9 综合报表导出

- 一键生成**独立 HTML 报告**，包含项目信息、月度数据、对比分析、财务分析、绿证数据
- 报告包含 Chart.js 图表，可在浏览器中直接查看
- 报告页眉自动显示用户设置的公司名称、地址、电话

## 三、特色功能

### 3.1 系统设置 — 个性化定制

- 可设置公司名称、地址、电话
- 设置保存后自动同步更新所有已存在项目的公司信息
- 标题栏和导出报告中动态显示公司信息，未设置时提示"请在系统设置中填写"

### 3.2 数据导出 / 导入 — 跨版本迁移

- **📤 导出**：一键将所有项目数据导出为 JSON 文件
- **📥 导入**：从 JSON 文件恢复数据，支持覆盖确认提示
- **旧版兼容**：自动识别旧版「全项目备份」格式并转换导入
- 适用于从浏览器版本迁移数据到桌面版本，或在不同电脑间同步数据

### 3.3 深色 / 浅色主题切换

- 一键切换深色 / 浅色模式，适应不同工作环境
- 所有图表、表格、卡片自动适配当前主题

### 3.4 数据安全

- 所有数据存储在本地（localStorage），不上传任何云端
- 每次备份生成独立 JSON 文件，可随时恢复
- CSV 导入导出支持月度数据、逐日数据、绿证数据单独操作

## 四、技术特点

| 项目 | 说明 |
|------|------|
| 运行环境 | Windows 10/11（需 WebView2 Runtime，系统通常已自带） |
| 程序形态 | 单文件 EXE（约 14MB），双击即用，无需安装 |
| 数据存储 | 本地 localStorage，持久化于 `%LOCALAPPDATA%\光伏收益分析系统\` |
| 图表引擎 | Chart.js 4.4.0（内置，离线可用） |
| 财务计算 | IRR 迭代求解 + NPV 折现计算 + 动态回收期 |
| 界面内核 | WebView2（基于 Chromium，与 Edge 浏览器同内核） |

## 五、适用场景

- **光伏电站投资方**：评估投资回报、追踪回本进度、管理多站点收益
- **光伏运维团队**：记录月度发电数据、对比安装前后效果、管理绿证出售
- **财务分析人员**：计算 IRR/NPV/ROI 等专业指标，生成可分享的综合报告
- **新能源企业管理层**：多项目汇总看板 + 雷达对比，一目了然掌握整体经营状况
